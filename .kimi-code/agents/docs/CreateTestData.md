## 6. 走查中发现的产品缺口（建议后续修复）

1. **行程列表依赖浏览器 localStorage**（`chpli2-trip-ids`）：服务端无行程列表端点，换浏览器/清缓存/换设备即「看不到行程」（数据还在）。建议补 `GET /api/travel/trips`。
2. **行程无删除 API、创建不支持客户端幂等 id**：误操作无法撤销（只能删交通段）；重试会产生重复行程。
3. **Travel → 日历同步写入旧 events API**：日历 UI 已 Memo 化，同步事件在日历模块**看不到**（仅 API 层存在，待 F4 决策退役或改造）。验证日历时看不到航班事件属预期。
4. 每日一句/侧栏折叠等偏好存 localStorage，换设备不跟随（与缺口 1 同类，优先级低）。
