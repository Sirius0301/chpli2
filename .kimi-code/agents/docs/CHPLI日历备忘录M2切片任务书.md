# CHPLI 日历备忘录（M2）切片任务书

> 范围：Memo 标签 + 两级筛选（标签 AND / 优先级 OR）+ 农历节气月视图。
> 不在本切片：图片上传与 DetailPanel 响应式（M3）、即将到期卡片/角标/浏览器通知（M4）、Portal 集成（M5）、按标签着色/标签管理界面（后续）。
> 依据：ROADMAP M1→M2 顺序；M1（2026-11-12）已交付 Memo 核心。
> 前置：M1 已交付。

## 一、切片目标

用户可以为 Memo 打标签（自由文本，非空去重）；在月/周/日视图外通过左侧筛选栏进行两级筛选——标签多选为 AND 语义（Memo 须同时含全部所选标签）、优先级多选为 OR 语义（Memo 优先级命中任一即显示）；中文 locale 下月视图每格显示农历日期（初一显示月名）与节气名，英文/德文环境不显示农历层，超出数据范围的年份静默缺省（不报错）。

## 二、数据模型

### 2.1 memos 增量（迁移 `memo_m2_tags`，仅加列，不改既有行）

| 字段 | 类型 | 说明 |
|---|---|---|
| tags | text[] | 标签数组，默认 {}；单标签 ≤32 字符，≤10 个，入库前 trim + 去重 |

标签为用户自有自由文本，不建独立标签表；标签候选清单由 2.3 的聚合端点提供。不跨用户共享标签命名空间。

### 2.2 筛选语义（两级）

- 标签筛选：多选 AND（`hasEvery`）——与任务书规格一致。
- 优先级筛选：多选 OR（`in`）。
- 两级之间为 AND（既命中标签条件，也命中优先级条件）。
- 不筛选 = 该维度不过滤；两维都不选 = 全量。

### 2.3 接口契约（相对 M1 的增量）

- `GET /api/memos` 新增可选查询参数：
  - `tags=a,b`：逗号分隔，AND 语义（Memo 须含全部）；单标签 ≤32 字符，超出 422。
  - `priorities=high,medium`：逗号分隔，OR 语义；非法枚举值 422。
- `GET /api/memos/tags` → `TagCountDto[]`（`{ tag: string, count: number }`，按 count 降序、tag 升序）：当前用户全部未删除 Memo 的标签聚合，供筛选栏候选（不受视图窗口限制）。
- `POST/PATCH /api/memos` 的 body 增加可选 `tags: string[]`；校验：每项非空 ≤32 字符、去重后 ≤10 个，否则 422 `VALIDATION_ERROR`。
- MemoDto 增加 `tags: string[]`。

## 三、核心决策

记录（2026-11-12）：

- **D1 农历库选型**：采用 `lunar-javascript`（六tail，MIT 许可，1900–2100 内置数据，节气为查表值准确可靠）。排除 `lunisolar`（GPL-3.0  copyleft 与本工程许可策略不合）、`solarlunar`（ISC 但维护活跃度与数据完整度不如前者）。依赖仅装于 `apps/calendar`（仅前端渲染需要）。
- **D2 农历数据范围**：1900-01-01 至 2100-12-31（库声明范围）。月视图窗口超出该范围时农历层静默缺省，与 E9 节假日降级一致；库在范围外不报错而是外推，故由前端自行边界判断，不信任库的外推值。
- **D3 农历显示策略**：仅 zh-CN locale 渲染农历层（中文产品语境）；en/de 不渲染（英文环境下农历显示策略按此关闭，属本切片决策，可后续推翻）。节气名以中文原样显示；农历日显示 `初一`…`三十`，初一/十一月/十二月显示月名（正月、冬月、腊月）。
- **D4 标签存储**：`text[]` 列（Postgres 原生数组），`hasEvery`/`has` 直接过滤，不建标签表；无级联、无独立标签生命周期。
- **D5 标签候选来源**：新增聚合端点 `GET /api/memos/tags`（全量、跨窗口），避免筛选后候选萎缩；count 便于后续排序展示。
- **D6 筛选持久化**：筛选条件存 localStorage（`chpli2-memo-filters`，与视图偏好一致，H4）；后端不保存筛选状态。
- **D7 农历计算位置**：纯前端（view-model 适配层 `lunar.ts`），后端无农历概念；单元测试覆盖适配层边界（范围内/外、节气日、初一）。

## 四、异常清单（增量）

| # | 场景 | 期望行为 |
|---|---|---|
| E52 | 标签 trim 后为空 / 去重后超过 10 个 | 422 `VALIDATION_ERROR`（服务层）；超长（>32）/ 数组超界由 DTO 层 400 拦截（沿用 400/422 分层） |
| E53 | `priorities` 含非法枚举值 | 422 `VALIDATION_ERROR` |
| E54 | 两个标签 AND 筛选无同时命中者 | 列表为空（200），前端显示空态 |
| E55 | 筛选后切换视图/翻页 | 筛选条件保持（ persisted，D6） |
| E56 | 月视图翻到 1900 前 / 2100 后 | 农历层静默缺省，其余渲染正常 |
| E57 | en/de locale 查看月视图 | 不渲染农历层，布局不受影响 |

## 五、前端交互

- 左侧筛选栏（Sidebar 回归，替代 M1 的纯主区布局）：「标签」区显示候选标签 + count 复选框（AND）；「优先级」区 4 个复选框（OR）；底部「清除筛选」；选中项即时生效并持久化（D6）。
- 两级筛选作用于三视图的数据源（后端过滤），标签候选始终来自聚合端点（D5）。
- 月视图：zh-CN 下每个日期格右上角显示农历日（初一显示月名，如「冬月」）；当日为节气时格内显示节气名（红色小字）；超出范围静默（E56）。
- DetailPanel 增加「标签」输入：逗号/回车添加为 chip，可单个移除；编辑回显已有标签。
- 三语文案同步；农历层不随语言切换翻译（D3）。

## 六、验收标准

- A48 创建/编辑 Memo 可添加标签，刷新后保留；E52 被拦截
- A49 单标签筛选命中；两个标签 AND 仅显示同时含两者的 Memo（E54 有空态）
- A50 优先级多选 OR 命中任一；标签 AND + 优先级 OR 两级组合正确
- A51 标签候选含 count 且不受当前筛选影响；清除筛选恢复全量
- A52 zh-CN 月视图显示农历日与节气（如 2026-11-22 小雪）；初一显示月名
- A53 en/de 月视图无农历层（E57）；2200 年月份正常渲染且无农历（E56）
- A41–A47 回归通过

## 七、测试覆盖要求

- **单元测试**：shared 无新增逻辑（标签/筛选在后端）；前端 lunar 适配层（范围内日期、节气日、初一/月名、范围外 null）；前端筛选状态解析。
- **集成测试**：tags 校验（E52）、筛选语义（A49/A50：AND/OR/组合/空态）、聚合端点（A51）、DTO 契约。
- **契约测试**：OpenAPI 新增 query 参数与 `/api/memos/tags` 路由 + TagCountDto；快照更新。
- **端到端测试**：建 Memo 打标签 → 两级筛选 → 清除；zh 月视图农历/节气可见；en 月视图无农历。既有 e2e 回归。
